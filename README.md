# PicPac App — мобильное приложение PicPac (хакатон, трек 2)

PWA для заказа фотокниг и печати фото в стиле super.picpac.by и админка для сотрудников: клиент работает с телефона, модератор и администратор — с компьютера. Все данные тестовые и синтетические.

## 1. Задача и ценность

**Задача (ТЗ, трек 2):** мобильный канал PicPac от фото на телефоне до заказа: каталог → проект → фото → проверка → корзина → тестовая оплата → номер заказа → статусы и поддержка, плюс админка с журналом действий.

- **Клиенту:** заказ с телефона без магазина приложений; черновик сохраняется сам и переживает обрыв связи; плохие фото видны **до** печати; правки словами и касанием («сделай теплее», «убери солнце»); статусы и ответы поддержки — в уведомлениях; двойное нажатие не создаёт второй заказ.
- **Фотопринту:** меньше перепечаток из-за ошибок в макете; заказы, обращения, модерация и смена статуса — в одной админке; статусы приходят событиями ERP; напоминание о забытой корзине; обезличенная статистика воронки ([метрики эффекта](docs/presentation-notes.md)).

Все функции по разделам — **[docs/features.md](docs/features.md)**.

## 5. Архитектура кратко

Браузер хранит черновики в IndexedDB и синхронизирует их с аккаунтом. Next.js на Vercel проверяет вход и роль, считает цены, пишет журнал. Supabase — Postgres с RLS, вход и закрытое хранилище фото (загрузка по подписанной ссылке). ИИ работает на устройстве; облачный ИИ (Cloudflare Workers AI) вызывает только сервер, после согласия клиента. Статусы меняют события ERP (на стенде — симулятор по pg_cron) через одну функцию базы; уведомления создают триггеры базы, важное уходит пушем. Схемы — [docs/architecture.md](docs/architecture.md).

## 7. Запуск за 15 минут

Нужны Node.js 20+, git и бесплатный аккаунт Supabase.

1. `git clone https://github.com/Vpragma/picpac-app.git && cd picpac-app && npm install` (репозиторий закрытый — нужен доступ).
2. supabase.com → New project; Settings → API — адрес и ключи; Settings → Database → Connection string (Direct) — строка подключения.
3. `cp .env.example .env.local` и впишите значения (раздел 8); `SEED_PASSWORD` и `ANALYTICS_SALT` придумайте сами. Команде проекта: `vercel env pull .env.local`.
4. `npm run db:migrate && npm run seed && npm run seed:catalog && npm run seed:demo` — таблицы, демо-аккаунты, каталог, демо-данные (повторный запуск безопасен).
5. `npm run dev` → http://localhost:3000 (или `npm run build && npm start`).

Проверки: `npm run test:all` (lint, сборка, unit, API, вход, e2e, доступность, лицензии); подробно — [docs/features.md](docs/features.md#проверки-и-тесты), результаты — [docs/test-report.md](docs/test-report.md).

## 9. Данные и их повторная загрузка

Нужен только `.env.local`, пароли в командах не нужны; повторный запуск безопасен.

| Команда | Что делает |
|---|---|
| `npm run seed` | демо-аккаунты (вернуть им пароль и роли) |
| `npm run seed:catalog` | каталог, доставка, промокоды |
| `npm run seed:demo` | синтетический набор и демо-проекты клиента |
| `npm run reset:demo` | вернуть демо в исходное состояние (`-- --dry-run` — только посчитать) |

Синтетический набор (ТЗ, раздел 8; seed 20261112): 200 клиентов, 523 заказа во всех статусах, 320 обращений, ~14 900 событий; реальных людей нет. Подробно — [docs/features.md](docs/features.md#демо-данные-и-синтетический-набор). Демо-аккаунты удалить нельзя — для проверки удаления зарегистрируйте свой.

## 11. Безопасность кратко

Права проверяет сервер (`proxy.js`, обработчик, RLS): без входа — 401, без роли — 403 (ОТ-02). httpOnly-cookie, лимит попыток входа, строгая CSP, схемы `zod`, лимиты частоты (429), заказ без дублей с суммой от сервера, приватное хранилище фото, неизменяемый журнал (ОТ-04), данные клиентов скрыты от сотрудников, 2FA по флагу. Подробно (SEC-01…24) — [docs/security.md](docs/security.md).

## 12. ИИ кратко

На устройстве (фото никуда не уходят): анализ качества, автоулучшение, команды словами, «убери солнце», выделение касанием (SlimSAM), «Размыть фон», ластик (MI-GAN), резкость ×2 (UpscalerJS), проверка фото для модерации (nsfwjs). В облаке (Cloudflare Workers AI) — только вошедшему клиенту после согласия: непонятную фразу разбирает `gpt-oss-120b` (уходит только текст), 20 правок в день. Подробно — [docs/ai.md](docs/ai.md).

## 15. Известные ограничения

- Напоминания о корзине по расписанию не включены — рассылку запускает кнопка в админке.
- Поиск предмета по слову не работает (облачная модель отвечает пустым) — работает касание.
- Пуш на реальных iPhone и Android не подтверждён (проверен в Chrome на Mac); на iPhone пуши — только из приложения на экране «Домой», iOS 16.4+.
- LCP главной 2,18–2,28 с при цели 2,0 с.
- Выделению касанием нужно ~2 ГБ памяти; на слабых телефонах оно выключено.
- Модерация: замены фото после возврата нет; проверка на устройстве — только первичный фильтр.
- «Убери солнце» — эвристика: солнце за дымкой может не найти.
- Нет: скелетов загрузки, кнопки «Позвать оператора», настройки тихих часов, кнопки отзыва согласия на облачный ИИ, правки каталога и пользователей в админке, сброса пароля.
- Оплата только тестовая; часть коэффициентов цен тестовая — уточнить у Фотопринт; настоящей ERP и CRM нет — задача пилота ([docs/pilot-plan.md](docs/pilot-plan.md)); облачный ИИ — Cloudflare (США), нужна правовая оценка.

Подробно — [docs/features.md](docs/features.md#12-известные-ограничения-подробно) и [docs/test-report.md](docs/test-report.md).
