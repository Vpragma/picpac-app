# PicPac App — мобильное приложение PicPac (хакатон, трек 2)

PWA для заказа фотокниг и печати фото в фирменном стиле PicPac (брендбук 2025, super.picpac.by) и админка для сотрудников: клиент работает с телефона, модератор и администратор — с компьютера. Все данные тестовые и синтетические.

## 1. Задача и ценность

**Задача (ТЗ, трек 2):** мобильный канал PicPac от фото на телефоне до заказа: каталог → проект → фото → проверка → корзина → тестовая оплата → номер заказа → статусы и поддержка, плюс админка с журналом действий.

- **Клиенту:** заказ с телефона без магазина приложений; черновик сохраняется сам и переживает обрыв связи; плохие фото видны **до** печати; правки словами и касанием («сделай теплее», «убери солнце»); статусы и ответы поддержки — в уведомлениях; двойное нажатие не создаёт второй заказ.
- **Фотопринту:** меньше перепечаток из-за ошибок в макете; заказы, обращения, модерация и смена статуса — в одной админке; статусы приходят событиями ERP; напоминание о забытой корзине; обезличенная статистика воронки ([метрики эффекта](docs/presentation-notes.md)).

Все функции по разделам — **[docs/features.md](docs/features.md)**.

## 4. Обязательный сценарий за 5 минут

1. **Каталог (гость).** Телефон или окно 390×844 → «Classic» → смените размер: цена и срок доставки пересчитываются сразу.
2. **Проект.** «Создать фотокнигу» → «Тестовая галерея» → «Добавить 12 фото». Перезагрузите страницу — фото и порядок на месте. «Автомакет» раскладывает фото по страницам.
3. **ИИ-правки.** «Правки»: у тёмного фото значки «Темно» и «Улучшено», ползунок «До / после». «Что изменить?» → «сделай теплее». «Закат» → «убери солнце». «Собака с мячом» → «Выделить касанием» → собака → «Размыть фон»; «Сбросить» → мяч → «Убрать».
4. **Проверка.** Добавьте `nesvizh-small` — предупреждение «будет нечётко» с выбором «Заменить фото» или «Продолжить всё равно» → «В корзину».
5. **Заказ.** Имя, телефон `+375 (29) 123-45-67`, промокод `TEST10`, «Европочта» и пункт выдачи, «ЕРИП (тест)» → «Подтвердить заказ» → вход `client@example.com` → корзина и форма целы → «Подтвердить заказ» → номер `PP-ГГММДД-NNNNN`.
6. **Ошибка сети.** Перед подтверждением выключите сеть (DevTools → Network → Offline): форма цела, понятная ошибка; включите сеть, «Повторить» дважды — заказ один.
7. **Статусы и поддержка.** «Открыть заказ»: 5 статусов с подэтапами, симулятор ERP двигает заказ каждые 30 с; уведомление «Заказ принят». «Написать в поддержку» → «Где мой заказ?» → бот отвечает статусом и датой доставки.
8. **Роли и журнал.** `/admin` под клиентом — «Нет доступа». `admin@example.com` → «Администратор» → «Заказы»: «На модерации», поиск по номеру, «Скачать CSV»; карточка заказа — всё в одном месте, «Сменить статус вручную» (нужна причина); обращение → «Ответить». «Журнал действий» — по умолчанию только люди за 7 дней, одинаковые подряд — «×N»; быстрый фильтр «Отказы».

9. **Промокоды и открытка (N8).** В корзине: `LETO2025` — «Истёк», `BIGBOOK30` — «минимальная сумма — 200,00 BYN», `OSEN2026` для печати фото — «не для этого продукта»; `OSEN2026` для фотокниги — −15%, скидка видна в итоге. После заказа — открытка с личным кодом на следующий заказ (−10%, 60 дней, один раз, только вам): «Сохранить картинкой» (PNG рисуется на устройстве), код виден в «Мои заказы». `admin@example.com` → «Промокоды»: применён раз и сумма заказов, «Новый промокод», «Изменить», «Выключить» (удаления нет), всё — в журнале. Сезонный код (`OSEN2026`, `BLACK2026`, `NEWYEAR2027`) действует и показывается плашкой на главной и в корзине, только когда включён его сезон.

Сценарий показа с модерацией и напоминанием о корзине — [docs/demo-script.md](docs/demo-script.md).

## 5. Архитектура кратко

Браузер хранит черновики в IndexedDB и синхронизирует их с аккаунтом. Next.js на Vercel проверяет вход и роль, считает цены, пишет журнал. Supabase — Postgres с RLS, вход и закрытое хранилище фото (загрузка по подписанной ссылке). ИИ-редактор работает целиком на устройстве: облачного ИИ нет, фото и текст команд для правок никуда не отправляются. Статусы меняют события ERP (на стенде — симулятор по pg_cron) через одну функцию базы; уведомления создают триггеры базы, важное уходит пушем. Схемы — [docs/architecture.md](docs/architecture.md).

**Сезоны (N2).** Админка → «Сезон»: «Без сезона», «Осень», «Чёрная пятница», «Новый год» — маркетинг меняет сезон без программиста. Настройка — в базе (`public.site_season`, миграция 0014: читать могут все, менять — только сервер после проверки роли admin), каждая смена — в журнале (`admin.season_set`). Сервер ставит `data-season` на `<html>`, открытые вкладки перечитывают `GET /api/v1/season` при возврате и раз в 30 секунд. Меняются только сезонные элементы: промо-плашка, баннер на главной (у осени — коллаж и листопад внутри баннера), линейная графика и цвет логотипа; кнопки, текст и фон — фирменные. Палитры — `docs/night/night2-seasons.md`. Микровзаимодействия (нажатия, появление карточек, шаги редактора, скелетоны, «полёт» в корзину, успех заказа) — `app/motion.css`: только `transform` и `opacity`, при `prefers-reduced-motion` выключены.

## 6. Стек

Next.js 16 и React 19 (JavaScript), Supabase (Postgres, RLS, Auth, Storage), `zod`, `@dnd-kit`, свой Service Worker (PWA, офлайн, пуши), `web-push`; ИИ в Web Worker — `@huggingface/transformers`, `@huggingface/tokenizers`, `onnxruntime-web`, `upscaler`, `@tensorflow/tfjs`; модерация — классификатор обнажённости Marqo ViT-tiny и CLIP ViT-B/32 (`onnxruntime-web` на устройстве и на сервере, `sharp`); pg_cron; тесты — Playwright, `node:test`, axe-core. Хостинг — Vercel. Шрифт Jost, стиль super.picpac.by.

**Скорость (N5):** фото — AVIF/WebP с размерами, приоритет только у фото первого экрана; шрифт Jost с нашего сайта (латиница + кириллица, preload, `swap`); ИИ, модерация и перетаскивание фото — только в воркерах и отдельными кусками кода по требованию; веса моделей кэшируются на год (`immutable`); сервис-воркер открывает оболочку при повторном входе сразу из кэша и обновляет её в фоне. Бюджет JS страниц — `npm run perf:budget` (нужен запущенный сервер); замеры «было → стало» — [docs/test-report.md](docs/test-report.md) (раздел N5).

**Оформление (N1):** фирменный стиль PicPac — шрифт Jost с нашего домена, токены в `app/picpac.css`, компоненты в `app/brand.css` ([docs/design-system.md](docs/design-system.md)); светлая тема по умолчанию у всех, тёмная и «как в системе» — в профиле.

## 7. Запуск за 15 минут

Нужны Node.js 20+, git и бесплатный аккаунт Supabase.

1. `git clone https://github.com/Vpragma/picpac-app.git && cd picpac-app && npm install` (репозиторий закрытый — нужен доступ).
2. supabase.com → New project; Settings → API — адрес и ключи; Settings → Database → Connection string (Direct) — строка подключения.
3. `cp .env.example .env.local` и впишите значения (раздел 8); `SEED_PASSWORD_CLIENT`, `SEED_PASSWORD_MODERATOR`, `SEED_PASSWORD_ADMIN` и `ANALYTICS_SALT` придумайте сами. Команде проекта: `vercel env pull .env.local`.
4. `npm run db:migrate && npm run seed && npm run seed:catalog && npm run seed:demo` — таблицы, демо-аккаунты, каталог, демо-данные (повторный запуск безопасен).
5. `npm run dev` → http://localhost:3000 (или `npm run build && npm start`).

Проверки: `npm run test:all` (lint, сборка, unit, API, вход, e2e, доступность, лицензии); подробно — [docs/features.md](docs/features.md#проверки-и-тесты), результаты — [docs/test-report.md](docs/test-report.md).

## 9. Данные и их повторная загрузка

Нужен только `.env.local`, пароли в командах не нужны; повторный запуск безопасен.

| Команда | Что делает |
|---|---|
| `npm run seed` | демо-аккаунты (вернуть им пароль и роли) |
| `npm run seed:catalog` | каталог, доставка, промокоды (`-- --promos-only` — только добавить новые демо-коды N8, существующие не меняются) |
| `npm run seed:demo` | синтетический набор и демо-проекты клиента |
| `npm run reset:demo` | вернуть демо в исходное состояние (`-- --dry-run` — только посчитать) |
| `npm run cleanup:test` | убрать тестовый мусор: аккаунты `e2e-…`, `critic-…`, `night2-…` старше 45 мин с их заказами, проектами, фото, корзинами и обращениями, «ничьи» заказы и запросы тестов, уведомления сотрудникам от автотестов и шагов симулятора ERP, файлы-сироты старше часа (`-- --dry-run` — только посчитать; перед удалением сам делает `db:backup`; журнал, синтетику и демо-аккаунты не трогает) |

Синтетический набор (ТЗ, раздел 8; seed 20261112): 200 клиентов, 523 заказа во всех статусах, 320 обращений, ~14 900 событий; реальных людей нет. Подробно — [docs/features.md](docs/features.md#демо-данные-и-синтетический-набор). Демо-аккаунты удалить нельзя — для проверки удаления зарегистрируйте свой.

### Админка (N9)

Только роль «Администратор», права проверяют `proxy.js`, обработчик и база; каждое изменение — в журнале.
- **Заказы** `/admin/orders`: поиск по номеру, статус, даты, продукт, «просрочен», «на модерации», источник (синтетика), сортировка, страницы; CSV — номер, дата, продукт, сумма, статус, город (без имён, телефонов, адресов и почты; выгрузка в журнале). Карточка заказа: суммы и оплата, состав с миниатюрами, лента статусов с причинами, решение модерации, переписка, действия по заказу.
- **Пользователи** `/admin/users`: поиск, роли модератора и администратора — выдать и снять; свои роли, демо-аккаунты и синтетику менять нельзя, последнего администратора не снять (функция базы `admin_set_role`).
- **Каталог** `/admin/catalog`: цены, коэффициенты размеров, плашки «новинка» / «скидка» / «выбор pic pac», старая цена (больше текущей — зачёркнута в каталоге). Сумму заказа всегда считает сервер.
- **Журнал действий**: не меняется и не удаляется (ОТ-04) — шум скрыт только на экране. По умолчанию — люди за 7 дней; «Показать также»: системные, ERP и симулятор, автотесты (признак `is_test` в представлении `audit_log_view`); одинаковые подряд — одной строкой «×N»; быстрые фильтры: входы, отказы, смены статуса, модерация, админские действия; страницы.
- **Статистика**: период сутки / 7 / 30 / 90 дней, воронка, корзина → оплата, промокоды (доля заказов, скидка, частые коды), ИИ-правки, просроченные заказы и обращения; синтетика — переключателем.

## 11. Безопасность кратко

Права проверяет сервер (`proxy.js`, обработчик, RLS): без входа — 401, без роли — 403 (ОТ-02). httpOnly-cookie, лимит попыток входа, строгая CSP (браузер соединяется только со своим сайтом и хранилищем Supabase — сторонние адреса блокируются), фото в хранилище без EXIF и GPS, схемы `zod`, лимиты частоты (429), заказ без дублей с суммой от сервера, приватное хранилище фото, неизменяемый журнал (ОТ-04), данные клиентов скрыты от сотрудников, 2FA по флагу. Автотесты безопасности: RLS каждой таблицы `public` (список берётся из базы), защитные заголовки страниц и API, лимиты частоты; `npm audit` — 0 уязвимостей. Подробно (SEC-01…24) — [docs/security.md](docs/security.md).

## 12. ИИ кратко

**Всё на устройстве, облака нет** (требование жюри, ночь 2): во время правок ни фото, ни текст команд, ни что-либо о содержимом фото не уходит с телефона. Анализ качества, автоулучшение, команды словами (синонимы, разговорные формы, опечатки, падежи), стили-пресеты («ч/б», «сепия», «винтаж», «как в старом кино», «тёплый вечер», «осеннее настроение»…), фразы вне словаря — маленькая модель rubert-tiny на устройстве подбирает команду по смыслу, поиск предмета словом («убери машину», «размой собаку», «осветли человека справа» — YOLOX-Nano + SlimSAM), выделение касанием, «Размыть фон», ластик (MI-GAN), резкость ×2 (UpscalerJS), быстрая проверка фото для модерации (Marqo ViT-tiny и CLIP ViT-B/32). Перед заказом наш сервер проверяет файлы сам теми же моделями (обнажённость, нацистская символика, оружие, кровь, наркотики), модератор видит вывод словами — «Найдено: обнажённая грудь (высокая уверенность)». Модели — с нашего сайта; после первой загрузки редактор работает без интернета. Где лежат фото: у гостя — на устройстве до заказа; у вошедшего клиента — в его аккаунте PicPac (наше закрытое хранилище), чтобы проект был на всех устройствах и его можно было напечатать. Правки по выделению (маски, ластик, «убери солнце» с координатами) в аккаунт не уходят — только общие параметры правок; печатная версия с ними собирается на телефоне. Доказательство — e2e `editor-local-ai.spec.mjs` (перехват всех запросов) и `editor-sync.spec.mjs` (вошедший клиент: ни масок, ни координат в запросах). Подробно — [docs/ai.md](docs/ai.md).

## 15. Известные ограничения

- Напоминания о корзине по расписанию не включены — рассылку запускает кнопка в админке.
- Поиск предмета словом знает 80 классов COCO (люди, машины, животные, вещи); небо, лицо, дом, дерево — касанием. Маленькие и далёкие предметы детектор может не найти — тогда редактор просит коснуться.
- «По смыслу» (rubert-tiny) угадывает команду не всегда: сразу выполняет только уверенные, иначе предлагает 3 кнопки.
- Пуш на реальных iPhone и Android не подтверждён (проверен в Chrome на Mac); на iPhone пуши — только из приложения на экране «Домой», iOS 16.4+.
- LCP 2,1–3,1 с при цели 2,0 с (Lighthouse, мобильный профиль; Performance 90–97, CLS 0): ответ сервера 0,3–0,9 с — функции Vercel в США, край во Франкфурте; перенос региона — решение команды.
- Выделению касанием нужно ~2 ГБ памяти; на слабых телефонах оно выключено.
