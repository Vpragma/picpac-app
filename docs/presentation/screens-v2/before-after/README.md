# Скриншоты «было / стало» (N1, 12.11.2026)

- `before-…` — основной сайт https://picpac-app-jade.vercel.app до редизайна (открытые экраны, без входа).
- `after-…` — ветка `night2-n1-redesign` на своём сервере (те же экраны; `staff-…` и `admin-…` — модератор и админ, вход временными пользователями `e2e-…@example.com`).
- `phone` — 390×844 @2x, `desktop` — 1440×900.
- `-dark` — тёмная тема: «было» — тема телефона (сайт сам переключался), «стало» — выбор в профиле (по умолчанию у всех светлая, даже если телефон в тёмном режиме).
- Экраны: 01 главная, 02 продукт Classic, 03 «Печать фото», 04 мои книги, 05 редактор, 06 корзина, 07 заказы, 08 профиль, 09 помощь, 10 вход.

Снять заново: `node scripts/screens-before-after.mjs <адрес> <before|after> [light|dark]`; экраны со входом — `N1SCREENS=1 BASE_URL=http://127.0.0.1:<порт> npx playwright test e2e/n1-screens.spec.mjs --project="телефон 390×844"`.
